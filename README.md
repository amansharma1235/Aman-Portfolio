## 🚀 How to Run Locally

You can run the portfolio using Node.js:

```bash
node server.js
```
Then visit: `http://localhost:3456/`

Or open `index.html` directly in any web browser!

---

## 🌐 Deployment

The project is structured ready for deployment:
- **Firebase Hosting**: Run `firebase deploy` (configured via `firebase.json`).
- **Vercel / Netlify / GitHub Pages**: Deploy the root directory with static publish path set to `.`.
