Aakriti Ultrasound — Diagnostic Healthcare Platform

Patient-Centric Medical Diagnostic & Clinic Consultation Web Portal
🏥 Featured Production Project
🟢 Live Production Web App 🩺 Doctor & Specialist Directory 🌓 Clinical Dual Themes 🛡️ Dedicated Backend Repository

Aakriti Ultrasound is a production-grade digital healthcare platform engineered for an advanced diagnostic ultrasound center. It streamlines clinical service discovery, patient test preparation, doctor credential exploration, and direct appointment scheduling. Designed with high-reliability patient communication channels (1-tap WhatsApp consultation, 24/7 emergency hotline, and live Google Maps clinic routing) and maintained with a dedicated backend repository.

✔ Specialist Medical Directory: Searchable radiologist and consultant catalog with specialization filters and consultation hours.
✔ Clinical Dual Theming: Medical-grade Dark & Light UI engineered for high readability in diagnostic clinic lighting.
✔ Zero-Friction Patient Support: One-tap emergency hotline, WhatsApp instant appointment booking, and GPS clinic navigation.
✔ Diagnostic Scan Procedures: Clear prep instructions, test requirements, and reporting guidelines for patients.
✔ Settings & Clinic Alerts: User preference management, theme persistence, and real-time operational notifications.
✔ Robust Backend Integration: Structured API repository maintaining clinic diagnostic endpoints and service records.

StudyMate — Student Helper & Smart Study Planner

Study · Plan · Achieve — Learn · Plan · Grow
🌟 Flagship Mobile Project
🟢 Live Production App 📱 Flutter 3.x Web & Mobile ⚡ Riverpod State Management 💾 Offline SQLite Caching

StudyMate is a comprehensive productivity and academic companion application engineered with Flutter & Dart. Built to help students overcome study fatigue, structure daily learning routines, and achieve peak academic focus with a distraction-free Pomodoro timer and real-time goal tracking.

✔ Pomodoro Timer with Strict Mode: 25-minute focus countdown with session counter, "Strict Mode" (leaving app withers tree 🥀), and ambient concentration soundscapes (Rain, etc.).
✔ Categorized Notes & Instant Search: Lecture notes organizer with dynamic category filtering (All, General, Computer Science) and real-time search.
✔ Tasks & Homework Planner: Structured assignment manager with segmented filters (All, Today, Upcoming, Done) and quick-add actions.
✔ Study Activity Matrix (Heatmap): GitHub-style interactive daily contribution heatmap tracking logged study hours and active streaks.
✔ Cloud Sync & Offline Persistence: Firebase Cloud Firestore sync + offline SQLite caching for uninterrupted study workflows.
✔ Security & Privacy: Native App Lock with Passcode protection 🔒 and one-click JSON data export.
